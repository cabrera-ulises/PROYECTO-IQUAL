# Presentación del Demo Day (24/11/2026)

Fuentes de la presentación final de IQUAL, 11 diapositivas: portada, problema, solución, módulos, demo, tecnología, competencia, presupuesto, qué le falta, conclusión y gracias.

- `deck.json`: orden y secciones.
- `deck.css`: estilos.
- `slides/*.html`: una diapositiva por archivo; el texto de cada `<aside>` es la nota del orador.
- Versión publicada: https://claude.ai/artifact/XXQcnLr4p93n7SgyTVUDto
- Guion por diapositiva: [`../GUION_PITCH.md`](../GUION_PITCH.md)

Cifras de la presentación: 47 tablas, 27 rutinas, 104 pruebas planificadas de la base de datos y 80 realizadas a mano en la aplicación. Los valores del presupuesto son estimaciones del equipo, no cotizaciones.

## Después del Demo Day
La lámina «Qué le falta a IQUAL» (`slides/pendientes.html`) se dejó tal como se expuso. Tres de las cosas que nombraba (recuperar la contraseña, pre-aprobación de productos e ID de usuario) se implementaron después: ver `README.md` de la raíz, sección «Funciones agregadas después del Demo Day».
